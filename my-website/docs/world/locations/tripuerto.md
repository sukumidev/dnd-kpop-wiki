El Tripuerto es una **infraestructura mágica de transporte**, no un lugar geográfico ni un reino. Se utiliza para trasladarse entre puntos de Hallyura.

Las sesiones pueden narrar el uso de un Tripuerto sin contabilizarlo como lugar visitado.
