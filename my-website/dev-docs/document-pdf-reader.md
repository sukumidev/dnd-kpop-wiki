# DocumentPdf en la Wiki

Contrato revisado contra [CMS PR #16](https://github.com/sukumidev/hallyura-cms/pull/16): `src` y `title` son obligatorios; `caption` y `display` son opcionales. `display` acepta `embedded` (valor predeterminado) o `card`. No se aceptan atributos adicionales, expresiones, hijos ni bloques anidados. La ruta debe seguir `/handouts/<documentId>/<slug>.pdf`, sin origen externo, query ni fragmento. El [PDF Asset Workflow del CMS PR #15](https://github.com/sukumidev/hallyura-cms/pull/15) genera normalmente un sufijo hash, que también cumple este contrato.

El componente usa el visor nativo del navegador para `embedded`, con carga diferida y una ruta pasada por el `baseUrl` de Docusaurus. La tarjeta no monta el iframe y no solicita el cuerpo del PDF; una solicitud `HEAD` comprueba si el archivo existe. El número de páginas y el tamaño no forman parte del MDX exportado y no se muestran. El título del archivo es texto editorial dentro del cuerpo; no crea una nueva cabecera de página ni altera las rutas de documentos.

En móvil se oculta el visor incrustado y se ofrece un aviso junto a los enlaces Abrir PDF y Descargar original. Esos enlaces están disponibles también si el navegador declara que no admite PDF incrustado. El control de páginas, zoom y calidad visual dentro del iframe dependen del navegador. El PDF se entrega sin extraer páginas ni convertirlo; los fixtures de prueba generan una circular de ocho páginas y un cuento vectorial de cinco páginas en horizontal.

La validación MDX bloquea rutas inseguras y comprueba que los PDFs de documentos publicados y públicos existan como archivos regulares durante la generación. La [política de publicación del PR #50](https://github.com/sukumidev/dnd-kpop-wiki/pull/50) copia sólo recursos de propietarios públicos; se actualizó para reconocer `DocumentPdf`. El [PR #49](https://github.com/sukumidev/dnd-kpop-wiki/pull/49) aporta `DocumentGallery`; ambos PR de lector usan el mismo contexto MDX. Este PR se basa en `main`; tras integrar #49 y #50 se debe revalidar el build público con un documento PDF real exportado por el CMS.
